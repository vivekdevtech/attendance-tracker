# Attendance Tracker

A simple Android app to track attendance for every subject, built by a B.Tech MnC student at Supaul College of Engineering (SCE), Supaul.

I found it hard to remember my attendance per subject and per teacher, so I built this.

## Features
- Overall and per-subject attendance percentage
- Daily timetable with Present / Absent / Cancelled buttons
- G1 / G2 lab group switch
- Go back to earlier days and fix forgotten ticks
- Holidays and Sundays are skipped automatically
- "Can miss X more classes" and "Attend X in a row" hints
- Backup and restore of all data
- Works fully offline

## Built with
HTML, CSS, JavaScript and Capacitor (Android)
